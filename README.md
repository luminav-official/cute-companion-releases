# Cute Companion for Windows

This repository contains versioned Windows downloads, release notes, and release verification workflows. Application source is maintained separately in a private repository.

No public release is available yet. Candidates are unsigned until their release notes explicitly state otherwise. A file checksum verifies integrity, not publisher trust.

Windows 11 x64 is the initial supported target. Download a published ZIP, extract it into a writable folder, then open `CuteCompanion.App.exe`. Settings are stored separately in `%LOCALAPPDATA%\CuteCompanion`. Quit the app before replacing or deleting its program folder. Keep the settings folder to retain preferences.
